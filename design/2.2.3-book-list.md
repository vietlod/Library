# 2.2.3 - Xem Danh Sách Sách (Book List)

## Tổng Quan
Luồng cho phép tất cả người dùng (kể cả chưa đăng nhập) xem danh sách sách với tìm kiếm, lọc và sắp xếp.

## Actor
- Tất cả người dùng (không cần đăng nhập)

## Mermaid Flowchart

```mermaid
flowchart TD
    Start([Người dùng vào trang Danh sách sách]) --> LoadPage[Load trang]
    LoadPage --> LoadBooks[Load danh sách sách - Trang 1]
    LoadBooks --> CheckEmpty{Có sách nào?}
    
    CheckEmpty -->|Không| ShowEmpty[Hiển thị: Chưa có sách]
    CheckEmpty -->|Có| DisplayBooks[Hiển thị danh sách sách]
    
    DisplayBooks --> ShowInfo[Hiển thị: Tên, Tác giả, Năm, Thể loại, Số lượng có sẵn, Số lượng đang mượn]
    ShowInfo --> UserAction{Thao tác?}
    
    UserAction -->|Tìm kiếm| InputSearch[Nhập từ khóa tìm kiếm]
    UserAction -->|Lọc| SelectCategory[Chọn thể loại]
    UserAction -->|Sắp xếp| SelectSort[Chọn tiêu chí sắp xếp]
    UserAction -->|Phân trang| ClickPage[Click trang tiếp theo]
    UserAction -->|Xem chi tiết| ClickBook[Click vào sách]
    
    InputSearch --> ApplySearch[Áp dụng tìm kiếm]
    ApplySearch --> FilterAPI[Gọi API với query params]
    
    SelectCategory --> ApplyFilter[Áp dụng lọc]
    ApplyFilter --> FilterAPI
    
    SelectSort --> ApplySort[Áp dụng sắp xếp]
    ApplySort --> FilterAPI
    
    ClickPage --> LoadPageNum[Load trang mới]
    LoadPageNum --> FilterAPI
    
    FilterAPI --> CheckResults{Có kết quả?}
    CheckResults -->|Không| ShowNoResults[Hiển thị: Không tìm thấy sách]
    CheckResults -->|Có| DisplayBooks
    
    ClickBook --> GoToDetail[Chuyển đến Trang chi tiết sách]
    
    ShowEmpty --> End([Kết thúc])
    ShowNoResults --> End
    GoToDetail --> End
```

## Các Bước Chi Tiết

### 1. Truy cập trang danh sách sách
- Người dùng vào `/books`
- Không cần đăng nhập

### 2. Load danh sách sách
- Load trang đầu tiên (10 sách/trang)
- Hiển thị thông tin:
  - Tên sách
  - Tác giả
  - Năm xuất bản
  - Thể loại
  - Số lượng có sẵn
  - Số lượng đang mượn

### 3. Tìm kiếm
- Input: Tên sách hoặc tác giả
- Tìm kiếm real-time hoặc khi nhấn Enter
- API: `GET /api/books?search=keyword`

### 4. Lọc theo thể loại
- Dropdown chọn thể loại
- API: `GET /api/books?category=categoryId`

### 5. Sắp xếp
- Options:
  - Tên (A-Z)
  - Năm xuất bản (Mới nhất)
  - Lượt mượn (Phổ biến nhất)
- API: `GET /api/books?sort=name|year|popular`

### 6. Phân trang
- 10 sách trên 1 trang
- Hiển thị số trang và nút Previous/Next
- API: `GET /api/books?page=1&limit=10`

### 7. Xem chi tiết
- Click vào sách → Chuyển đến `/books/:id`

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/api/books` | Lấy danh sách sách (có query params) |
| GET | `/api/categories` | Lấy danh sách thể loại (để lọc) |

## Query Parameters

| Param | Type | Description |
|-------|------|-------------|
| `search` | string | Tìm kiếm theo tên/tác giả |
| `category` | number | Lọc theo thể loại ID |
| `sort` | string | Sắp xếp: `name`, `year`, `popular` |
| `page` | number | Số trang (mặc định: 1) |
| `limit` | number | Số lượng mỗi trang (mặc định: 10) |

## Response Format

```json
{
  "data": [
    {
      "id": 1,
      "title": "Tên sách",
      "author": "Tác giả",
      "year": 2023,
      "category": {
        "id": 1,
        "name": "Thể loại"
      },
      "available": 5,
      "borrowed": 3
    }
  ],
  "pagination": {
    "page": 1,
    "limit": 10,
    "total": 100,
    "totalPages": 10
  }
}
```

## Error Handling

| Lỗi | Thông báo | Status Code |
|-----|-----------|-------------|
| Mất kết nối | "Không thể tải danh sách sách" | - |
| API timeout | "Tải dữ liệu quá lâu, vui lòng thử lại" | - |
| Trang không tồn tại | "Trang không tồn tại" | 404 |
